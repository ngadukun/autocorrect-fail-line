The funniest autocorrect fail — an innocent message, one word swapped, and a landlord left with follow-up questions nobody can answer:

> **I texted my landlord "the sink is leaking" — autocorrect sent "the sink is leaving", and now he wants to know where it is going.**

## Run it

```sh
python3 main.py
```

Prints the fail to stdout and nothing else. Python standard library only, deterministic, no files written.
